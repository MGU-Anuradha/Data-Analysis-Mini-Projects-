# Data Analytics Mini Projects

Welcome to my **Data Analytics Mini Projects** repository!  
This collection consists of hands-on mini projects designed to explore a variety of real-world data tasks such as **data cleaning**, **SQL-based EDA**, **Excel dashboards**, **Python scripting**, **web scraping**, and **data visualization** using **Power BI** and **Tableau**.

Each project is independently structured and aims to strengthen foundational concepts and tools commonly used in data analytics workflows.

---

## 🧩 Projects Overview

### 1. Data Cleaning in SQL
- **Description:** Focused on cleaning and transforming raw, messy datasets using SQL queries.
- **Skills:** SQL functions, NULL handling, column transformation, filtering.


### 2. SQL EDA (Exploratory Data Analysis) Project
- **Description:** Conducted exploratory analysis using SQL queries to understand patterns and extract insights from raw data.
- **Skills:** Joins, aggregations, grouping, filtering, subqueries.


### 3. Excel Dashboard: Bike Sales Analysis
- **Description:** Created a dynamic Excel dashboard from raw bike sales data.
- **Skills:** Pivot tables, slicers, data visualization in Excel.


### 4. Power BI Dashboard: Work-Life Balance Survey
- **Description:** Analyzed and visualized survey data on professionals' work-life balance using Power BI.
- **Skills:** Power Query, measures (DAX), visuals, interactive filtering.


### 5. Tableau Dashboard: Airbnb Analysis
- **Description:** Designed an interactive Tableau dashboard based on raw Airbnb data.
- **Skills:** Calculated fields, filters, charts, mapping, storytelling.


### 6. Python File Sorter: File Handling Automation
- **Description:** A Python automation project to sort and organize files based on their file types.
- **Skills:** File system navigation, automation using Python `os` and `shutil` modules.


### 7. Web Scraping with Pandas
- **Description:** A simple web scraping project using Python and Pandas to extract tabular data from a website.
- **Skills:** `requests`, `BeautifulSoup`, `pandas`, data extraction and structuring.
